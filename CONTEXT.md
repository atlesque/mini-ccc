# Mini CCC context

## Schedule

- **Agenda** — the fixed, read-only arrangement of schedule blocks inside the 10:00–22:00 event window. Users can export it as a text file.
- **Schedule block** — one activity that occupies one or more half-hour slots. The published agenda does not allow blocks to be added, removed, resized, or reordered.
- **Open time** — a gap with no schedule block.

## Catalogues

- **Build** — a Mini CCC electronics project with a parts list and estimated cost.
- **Watch item** — a curated external YouTube recommendation shown on the Videos page.
- **Cocktail** — a Club-Mate drink recipe. The collection includes both alcoholic and alcohol-free serves.
